# CimBar Docs Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A five-language user guide, privacy policy and support page, served at `https://nfcarchiver.com/cimbar/docs/` and mirrored at `https://mezinster.github.io/cimbar/`.

**Architecture:** MkDocs + Material in `site-docs/`, copied from NFC Archiver's `site-docs/` and adapted. Built twice with different `site_url`s. The main copy goes to S3 prefix `cimbar-docs/`, and a CloudFront viewer-request rewrite serves it at `/cimbar/docs/`. Deploys are manual through `deploy-docs.yml`.

**Tech Stack:** MkDocs 1.6, mkdocs-material 9, mkdocs-static-i18n 1.3, Python 3.12, GitHub Actions, Terraform (CloudFront Functions JS 2.0, IAM).

**Spec:** `docs/superpowers/specs/2026-11-15-docs-site-design.md`

## Global Constraints

- Locales: en (root), ru, uk, tr, ka. They are read from `app/lib/l10n/app_*.arb`.
- Contact: `support@nfcarchiver.com` on privacy.md and support.md in every locale.
- Build marker: `<meta name="cimbar-docs-build" content="<full sha>">`.
- Canonical links: `https://nfcarchiver.com/cimbar/docs/<page.url>` in both copies.
- Base paths: `/cimbar/docs/` for the main copy, `/cimbar/` for Pages.
- S3 prefix: exactly `cimbar-docs/`, which must differ from `S3_PREFIX` (`cimbar/`). Invalidate `/cimbar/docs/*`.
- Nothing third-party is loaded (`font: false`).
- No AWS IDs or ARNs in the repo or in logs.
- User-facing text says "CimBar-XL" and credits sz3's libcimbar as inspiration. Never write "CimBar v2" or "successor".
- UI labels are quoted exactly from the ARB files.

## Review Focus

- `/cimbar/docs` with no trailing slash → 302 to `/cimbar/docs/`. Then `/cimbar/docs/ru/privacy/` → `/cimbar-docs/ru/privacy/index.html`. *Task 1 node check.*
- `/cimbar/docsx/` and `/cimbar/` must NOT be rewritten. *Task 1 node check.*
- A web app deploy leaves the docs intact: separate prefix, nothing to test beyond the IAM prefix.
- The Pages copy must contain no `/cimbar/docs/` link (`check_site.py --built` on Pages).
- Every translated privacy page links to the English one as authoritative (`check_site.py` source check).
