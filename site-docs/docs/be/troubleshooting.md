# Вырашэнне праблем

## Сканер не знаходзіць код

- Змясціце ўвесь код у квадрат, пакінуўшы невялікі адступ вакол. Усе чатыры кутнія квадраты павінны быць бачныя.
- Павялічце яркасць экрана адпраўшчыка і пазбягайце адлюстраванняў лямпаў або вокнаў на ім.
- Трымайце тэлефон нерухома і прыкладна паралельна экрану.
- Выконвайце падказку на экране: **Падыдзіце бліжэй**, **Адсуньцеся далей**, **Трымайце нерухома**, **Змяніце вугал або асвятленне** (у вэб-праграме: **Трымайце камеру роўна насупраць экрана**).
- **Вэб-праграма:** для сканавання камерай старонка павінна быць адкрыта праз `https://`. Калі браўзер запытаў доступ да камеры, а вы адмовілі, дазвольце яго ў наладах сайта ў браўзеры.
- **Праграма:** калі вы забаранілі доступ да камеры, дазвольце яго для CimBar у наладах сістэмы.

## Лічыльнік перастаў расці

- Не спыняйце паказ кода. У паказанага кода новыя кадры не заканчваюцца; GIF паўтараецца, таму дачакайцеся наступнага круга.
- Для доўгіх кодаў выберыце на баку адпраўшчыка павольнейшую хуткасць (400 мс): тэлефон можа прапускаць кадры, якія змяняюцца занадта хутка.
- Хвалістыя палосы на экране (муар) узнікаюць з-за накладання сеткі пікселяў камеры і экрана: адыдзіце крыху далей або трохі змяніце вугал.

## «Кадраў у файле: N — выкарыстоўвайце „Жывое сканаванне“»

На фота змяшчаецца толькі адзін кадр. У праграме фота падыходзіць толькі для кодаў з аднаго кадра; для даўжэйшых выкарыстоўвайце **Жывое сканаванне**.

## Вэб-праграма пытаецца, ці скінуць бягучае сканаванне

Фота або кадр, які вы толькі што дадалі, належыць іншаму файлу, чым той, што збіраецца. Выберыце, ці пакінуць ужо сабраныя кадры, ці пачаць нанова з новым файлам.

## Няправільны пароль

Увядзіце яго яшчэ раз: кадры захаваны, сканаваць зноў не трэба. У паролях адрозніваюцца вялікія і малыя літары. Калі пароль ніхто не ведае, файл адкрыць не атрымаецца. Гл. [Шыфраванне](encryption.md).

## «Недапушчальны або непадтрымліваемы файл GIF»

Гэты GIF не з’яўляецца кодам CimBar або быў зменены па дарозе: некаторыя мэсэнджары пераціскаюць GIF або ператвараюць іх у відэа. Адпраўце яго як файл (дакумент) або выкарыстайце **Паказаць на экране** і скануйце напрамую. GIF самых ранніх выпускаў праекта бягучыя версіі не чытаюць.

## «Файл занадта вялікі для апрацоўкі»

Файл большы, чым можа апрацаваць CimBar. Для адпраўкі праз **Падзяліцца GIF** трымайце код у межах 500 кадраў; **Паказаць на экране** спраўляецца з кодамі да 4096 кадраў.

## Праграма не можа адкрыць атрыманы файл

«На гэтым тэлефоне няма праграмы, якая можа адкрыць гэты файл» азначае, што ніводная ўсталяваная праграма не працуе з такім тыпам файлаў. Выкарыстайце **Захаваць на прыладу** або перашліце файл.
