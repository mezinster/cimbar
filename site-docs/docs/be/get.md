# Усталяванне

## Вэб-праграма { #web-app }

Адкрыйце **[nfcarchiver.com/cimbar](https://nfcarchiver.com/cimbar/)** у браўзеры. Яна працуе на тэлефонах і камп’ютарах і не патрабуе ні ўсталявання, ні ўліковага запісу.

Для сканавання камерай старонка павінна быць адкрыта праз `https://` (як па гэтым адрасе). Копія, адкрытая з файла на камп’ютары, па-ранейшаму можа адпраўляць і дэкадаваць GIF або фота, але браўзер не запусціць у ёй сканер камеры.

## Android { #android }

Праграма называецца **CimBar Scanner**. Патрэбны Android 7.0 або навейшы. Яна запытвае адзін дазвол — камеру — і не мае доступу да інтэрнэту.

- **[F-Droid](https://f-droid.org/packages/com.nfcarchiver.cimbar/)**: F-Droid збірае праграму з апублікаванага зыходнага кода і абнаўляе яе аўтаматычна праз праграму F-Droid.
- **[Выпускі на GitHub](https://github.com/mezinster/cimbar/releases)**: APK далучаны да кожнага выпуску.

!!! note "Зборкі F-Droid і GitHub не змешваюцца"
    F-Droid падпісвае свае зборкі ўласным ключом, таму APK з GitHub не можа абнавіць усталяванне з F-Droid, і наадварот. Каб перайсці на іншую крыніцу, захавайце дэкадаваныя файлы, выдаліце праграму і ўсталюйце яе з іншай крыніцы.

У версій да 0.10.1 уключна быў іншы ідэнтыфікатар праграмы (`com.cimbar.scanner`). Навейшыя версіі ўсталёўваюцца побач са старой праграмай, а не замяняюць яе. Захавайце са старой патрэбныя файлы, а потым выдаліце яе.

## iPhone і iPad { #iphone }

**CimBar** для iPhone і iPad (iOS 15 або навейшы) праходзіць тэсціраванне ў Apple **TestFlight** і пакуль не апублікаваны ў App Store. Да таго часу [вэб-праграма](#web-app) працуе ў Safari на iPhone і iPad, уключаючы сканаванне камерай.
