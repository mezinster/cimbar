# Шыфраванне

Калі вы адпраўляеце з паролем, файл або паведамленне шыфруецца на вашай прыладзе, перш чым стаць кодам. Адсканаваць код можа любы, але адкрыць тое, што ён нясе, можа толькі той, хто ведае пароль.

- **Алгарытм:** AES-256-GCM. Ключ атрымліваецца з пароля з дапамогай PBKDF2-SHA256 (150 000 ітэрацый) і выпадковай солі для кожнага файла.
- **Пароль ніколі не пакідае вашу прыладу.** Ён не захоўваецца, не запісваецца ў журналы і нікуды не адпраўляецца.
- **Атрымальніку не трэба ведаць пра гэта загадзя.** CimBar сам распазнае зашыфраваны файл і спытае пароль, калі збяруцца ўсе кадры.
- **Няправільны пароль нічога не каштуе.** Кадры ўжо сабраны: увядзіце пароль яшчэ раз, без паўторнага сканавання.

!!! warning "Страчаны пароль немагчыма аднавіць"
    Ніхто, у тым ліку мы, не можа адкрыць зашыфраваны файл без яго пароля.

Перадайце атрымальніку пароль іншым спосабам, не праз сам код, напрыклад асабіста.
