# CimBar

CimBar перадае файл або тэкставае паведамленне з аднаго экрана ў камеру ў выглядзе аніміраванага кода з каляровых фігур. Нічога не ідзе праз сетку, не патрэбны ні кабель, ні спалучэнне прылад. Адпраўленае можна зашыфраваць паролем. Усё адбываецца на вашых уласных прыладах.

## Як карыстацца

1. **[Адпраўце](send.md):** выберыце файл або набярыце паведамленне. CimBar ператворыць яго ў аніміраваны код.
2. **Пакажыце** код на экране або падзяліцеся ім як GIF.
3. **[Прыміце](receive.md):** навядзіце на код камеру іншай прылады і пачакайце, пакуль збяруцца ўсе кадры.

Любы кліент можа адпраўляць любому іншаму: тэлефон можа прымаць з вэб-праграмы, а вэб-праграма — з тэлефона.

У раздзеле [Як гэта працуе](how-it-works.md) расказваецца, што знаходзіцца ўнутры кода. Пра паролі — у раздзеле [Шыфраванне](encryption.md).
