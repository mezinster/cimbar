# Receive

There are three ways to receive. Every way ends with the same result: a file you can open, save or share, or a text message you can copy.

## Scan with the camera (recommended)

This is the way to receive a code that someone is presenting on a screen.

**In the app:** open the **Camera** tab and tap **Live Scan**. **In the web app:** open **Receive**. The camera opens straight away.

1. Fit the barcode inside the square.
2. Follow the hints: **Move closer**, **Move back**, **Hold still**, **Adjust angle or lighting**.
3. The counter shows how many frames are in. When it reaches the total, the file opens.

The frames can arrive in any order, and frames you missed don't matter: any frames of the file will do, as long as there are enough of them.

## Import a GIF

When someone shared a CimBar GIF with you:

- **App:** open the **Import GIF** tab and **Select File**, or share the GIF from another app straight into CimBar (Android share menu, or the iPhone share sheet).
- **Web app:** in **Receive**, use **Choose a GIF** (or drop it on the page).

## Photograph a frame

- **App:** in the **Camera** tab, **Take Photo** or pick one from the **Gallery**. A photo holds one frame, so this works only for codes of a single frame. For a longer code, the app tells you to use **Live Scan**.
- **Web app:** **Photograph frames** accepts one photo per frame and keeps collecting until every frame is in. It also accepts a photo of a frame through **Choose a GIF**.

If a photo belongs to a different file than the one you are collecting, the web app asks before it starts over.

## Encrypted files

If the file was encrypted, you are asked for the passphrase once all frames are in. There is no need to scan again: if you get the passphrase wrong, just enter it again. See [Encryption](encryption.md).

## Where received files go

**App:** a received file is kept in the app and listed in the **Files** tab. From there, **Open** it in another app, **Save to device**, share it, or **Delete** it. A text message is shown with **Copy** and **Share text**. Uninstalling the app deletes the files it kept, so save the ones you need.

**Web app:** nothing is downloaded automatically. Choose **Save to device**, **Open** (for file types that are safe to show), or **Share**. A text message is shown with **Copy** and **Save as .txt**.
