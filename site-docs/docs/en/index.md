# CimBar

CimBar sends a file or a text message from one screen to a camera as an animated code of coloured shapes. Nothing goes over a network, and there is no cable or pairing. A passphrase can encrypt what you send. Everything happens on your own devices.

## How to use it

1. **[Send](send.md):** choose a file or type a message. CimBar turns it into an animated code.
2. **Show** the code on the screen, or share it as a GIF.
3. **[Receive](receive.md):** point another device's camera at it, and wait until every frame is in.

Any client can send to any other: a phone can receive from the web app, and the web app can receive from a phone.

[How it works](how-it-works.md) explains what is inside the code. [Encryption](encryption.md) covers passphrases.
