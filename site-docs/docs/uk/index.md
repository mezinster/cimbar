# CimBar

CimBar передає файл або текстове повідомлення з одного екрана на камеру у вигляді анімованого коду з кольорових фігур. Нічого не йде через мережу, не потрібні ні кабель, ні сполучення пристроїв. Те, що ви надсилаєте, можна зашифрувати паролем. Усе відбувається на ваших власних пристроях.

## Як ним користуватися

1. **[Надішліть](send.md):** виберіть файл або введіть повідомлення. CimBar перетворить його на анімований код.
2. **Покажіть** код на екрані або поділіться ним як GIF.
3. **[Отримайте](receive.md):** наведіть на код камеру іншого пристрою й дочекайтеся, поки надійдуть усі кадри.

Будь-який клієнт може надсилати будь-якому іншому: телефон може отримати файл із вебзастосунку, а вебзастосунок — із телефона.

[Як це працює](how-it-works.md) пояснює, що всередині коду. Про паролі — у розділі [Шифрування](encryption.md).
