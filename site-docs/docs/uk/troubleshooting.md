# Вирішення проблем

## Сканер не знаходить код

- Розмістіть увесь код усередині квадрата з невеликим відступом довкола. Усі чотири кутові квадрати мають бути видимі.
- Підвищте яскравість екрана, що показує код, і уникайте відблисків ламп чи вікон на ньому.
- Тримайте телефон нерухомо й приблизно паралельно екрану.
- Дотримуйтеся підказки на екрані: **Піднесіть ближче**, **Відсуньте далі**, **Тримайте нерухомо**, **Adjust angle or lighting**.
- **Вебзастосунок:** для сканування камерою сторінку треба відкрити через `https://`. Якщо браузер запитував доступ до камери і ви відмовили, дозвольте його в налаштуваннях сайту в браузері.
- **Застосунок:** якщо ви відмовили в доступі до камери, дозвольте його в системних налаштуваннях для CimBar.

## Лічильник перестав зростати

- Не зупиняйте код. Показаний код ніколи не вичерпує нових кадрів; GIF повторюється, тож дочекайтеся наступного циклу.
- Для довгих кодів виберіть на пристрої-відправнику повільнішу швидкість (400 мс): телефони можуть пропускати кадри, що змінюються надто швидко.
- Хвилясті смуги на екрані (муар) виникають через камеру й піксельну сітку екрана: відійдіть трохи далі або злегка змініть кут.

## «This file spans N frames — use Live Scan»

Фото містить лише один кадр. У застосунку фото підходить тільки для кодів з одного кадру; для довших скористайтеся **Живе сканування**.

## Вебзастосунок питає, чи скинути поточне сканування

Фото чи кадр, який ви щойно додали, належить іншому файлу, ніж той, що збирається зараз. Виберіть, чи зберегти вже зібрані кадри, чи почати заново з новим файлом.

## Неправильний пароль

Введіть його ще раз: кадри збережено, тож сканувати знову не треба. Паролі чутливі до регістру. Якщо пароля ніхто не знає, файл відкрити не вдасться. Див. [Шифрування](encryption.md).

## «Недійсний або непідтримуваний GIF файл»

Цей GIF не є кодом CimBar або його змінили дорогою: деякі месенджери повторно стискають GIF чи перетворюють їх на відео. Надішліть його як файл (документ) або скористайтеся **Показ** і скануйте напряму. GIF-файли з найперших версій проєкту поточні версії не читають.

## «Файл занадто великий для обробки»

Файл більший, ніж може обробити CimBar. Для надсилання тримайте коди для **Поділитися GIF** у межах 500 кадрів; **Показ** підтримує до 4096.

## Застосунок не може відкрити отриманий файл

«На цьому телефоні немає застосунку, який може відкрити цей файл» означає, що жоден встановлений застосунок не працює з таким типом файлів. Натомість скористайтеся **Зберегти на пристрій** або поділіться ним.
