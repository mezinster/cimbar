# Підтримка

Пишіть на [support@nfcarchiver.com](mailto:support@nfcarchiver.com) або створіть issue на [GitHub](https://github.com/mezinster/cimbar/issues).

## Що вказати

Щоб ми могли відтворити проблему, будь ласка, повідомте:

- яким клієнтом ви користувалися: вебзастосунком (і яким браузером), застосунком для Android чи для iPhone;
- модель пристрою та версію системи;
- версію застосунку — її видно у вкладці **Інфо** (у вебзастосунку — внизу сторінки **Як це працює**);
- надсилали ви чи отримували, і яким способом (показ на екрані, GIF, живе сканування, фото);
- що ви робили і що сталося замість очікуваного.

Будь ласка, не надсилайте вміст своїх файлів і жодних паролів.
