# Завантажити застосунок

## Вебзастосунок { #web-app }

Відкрийте **[nfcarchiver.com/cimbar](https://nfcarchiver.com/cimbar/)** у браузері. Він працює на телефонах і комп'ютерах, не потребує встановлення чи облікового запису.

Щоб сканувати камерою, сторінку треба відкрити через `https://` (як за цією адресою). Копія, відкрита з файлу на вашому комп'ютері, теж уміє надсилати й розшифровувати GIF чи фото, але сканер камери браузери в ній не запустять.

## Android { #android }

Застосунок називається **CimBar Scanner**. Потрібен Android 7.0 або новіший. Він просить лише один дозвіл — камеру — і не має доступу до інтернету.

- **[F-Droid](https://f-droid.org/packages/com.nfcarchiver.cimbar/)**: F-Droid збирає його з опублікованого вихідного коду, а оновлення приходять автоматично через застосунок F-Droid.
- **[Релізи на GitHub](https://github.com/mezinster/cimbar/releases)**: APK-файл, прикладений до кожного релізу.

!!! note "Збірки з F-Droid і GitHub несумісні"
    F-Droid підписує свої збірки власним ключем, тому APK з GitHub не може оновити версію з F-Droid, і навпаки. Щоб перейти на інше джерело, збережіть отримані файли, видаліть застосунок і встановіть його з іншого джерела.

Версії до 0.10.1 включно мали інший ідентифікатор застосунку (`com.cimbar.scanner`). Новіші версії встановлюються поруч зі старим застосунком, а не замість нього. Збережіть потрібні файли зі старого й видаліть його.

## iPhone та iPad { #iphone }

**CimBar** для iPhone та iPad (iOS 15 або новіша) проходить тестування в Apple **TestFlight** і поки що відсутній в App Store. Доти [вебзастосунок](#web-app) працює в Safari на iPhone та iPad, зокрема й сканування камерою.
