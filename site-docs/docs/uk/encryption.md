# Шифрування

Коли ви надсилаєте з паролем, файл чи повідомлення шифрується на вашому пристрої ще до того, як стане кодом. Відсканувати код може будь-хто, але відкрити його вміст — лише той, хто знає пароль.

- **Алгоритм:** AES-256-GCM. Ключ виводиться з вашого пароля за допомогою PBKDF2-SHA256 (150 000 ітерацій) і випадкової «солі», окремої для кожного файлу.
- **Пароль ніколи не залишає ваш пристрій.** Він не зберігається, не записується в журнали й нікуди не надсилається.
- **Отримувачу не треба знати заздалегідь.** CimBar сам розпізнає зашифрований файл і запитує пароль, коли надійдуть усі кадри.
- **Помилка в паролі нічого не коштує.** Кадри вже зібрано: просто введіть пароль ще раз, сканувати знову не треба.

!!! warning "Втрачений пароль не відновити"
    Ніхто, зокрема й ми, не зможе відкрити зашифрований файл без пароля.

Повідомте отримувачу пароль якимось іншим способом, ніж сам код, наприклад особисто.
