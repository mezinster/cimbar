# დაშიფვრა

როცა პაროლით აგზავნით, ფაილი ან შეტყობინება თქვენს მოწყობილობაზე იშიფრება, სანამ კოდად იქცევა. კოდის დასკანერება ნებისმიერს შეუძლია, მაგრამ მის შიგთავსს მხოლოდ ის გახსნის, ვინც პაროლი იცის.

- **ალგორითმი:** AES-256-GCM. გასაღები თქვენი პაროლიდან მიიღება PBKDF2-SHA256-ით (150,000 იტერაცია) და ყოველი ფაილისთვის შემთხვევითი მარილით (salt).
- **პაროლი თქვენს მოწყობილობას არასდროს ტოვებს.** ის არ ინახება, არ იწერება ჟურნალში და არსად იგზავნება.
- **მიმღებმა წინასწარ არაფერი უნდა იცოდეს.** CimBar დაშიფრულ ფაილს თავად ცნობს და პაროლს მას შემდეგ ითხოვს, რაც ყველა კადრი შემოვა.
- **არასწორი პაროლი არაფერს გაფუჭებს.** კადრები უკვე შეგროვებულია: უბრალოდ ხელახლა შეიყვანეთ პაროლი, თავიდან სკანირება არ დაგჭირდებათ.

!!! warning "დაკარგული პაროლის აღდგენა შეუძლებელია"
    დაშიფრულ ფაილს პაროლის გარეშე ვერავინ გახსნის, მათ შორის ჩვენც.

პაროლი მიმღებს თავად კოდისგან განსხვავებული გზით შეატყობინეთ, მაგალითად, პირადად.
