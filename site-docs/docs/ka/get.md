# აპის მიღება

## ვებ-აპი { #web-app }

გახსენით **[nfcarchiver.com/cimbar](https://nfcarchiver.com/cimbar/)** ბრაუზერში. ის მუშაობს ტელეფონებსა და კომპიუტერებზე და არც დაყენებას საჭიროებს, არც ანგარიშს.

კამერით სკანირებისთვის გვერდი `https://`-ით უნდა იყოს გახსნილი (როგორც ამ მისამართზეა). კომპიუტერზე ფაილიდან გახსნილ ასლს მაინც შეუძლია გაგზავნა და GIF-ის ან ფოტოების გაშიფვრა, მაგრამ ბრაუზერები მის კამერის სკანერს არ ჩართავენ.

## Android { #android }

აპს **CimBar Scanner** ჰქვია. მას Android 7.0 ან უფრო ახალი სჭირდება. ის მხოლოდ ერთ ნებართვას ითხოვს — კამერას — და ინტერნეტზე წვდომა არ აქვს.

- **[F-Droid](https://f-droid.org/packages/com.nfcarchiver.cimbar/)**: F-Droid თავად აგებს მას გამოქვეყნებული კოდიდან და ის ავტომატურად ახლდება F-Droid-ის აპის მეშვეობით.
- **[GitHub releases](https://github.com/mezinster/cimbar/releases)**: APK ფაილი, რომელიც თითოეულ რელიზს ერთვის.

!!! note "F-Droid-ისა და GitHub-ის ვერსიები ერთმანეთს არ ერწყმის"
    F-Droid საკუთარი გასაღებით აწერს ხელს თავის ვერსიებს, ამიტომ GitHub-ის APK ვერ განაახლებს F-Droid-იდან დაყენებულ აპს და პირიქით. გადასასვლელად შეინახეთ მიღებული ფაილები, წაშალეთ აპი და დააყენეთ მეორე წყაროდან.

0.10.1-მდე ვერსიებს სხვა აპის ID ჰქონდა (`com.cimbar.scanner`). შემდგომი ვერსიები ძველი აპის გვერდით დგება და არ ცვლის მას. შეინახეთ ძველიდან ის ფაილები, რომლებიც გჭირდებათ, შემდეგ კი წაშალეთ იგი.

## iPhone და iPad { #iphone }

**CimBar** iPhone-ისა და iPad-ისთვის (iOS 15 ან უფრო ახალი) ამჟამად Apple-ის **TestFlight**-ზე იტესტება და App Store-ში ჯერ არ არის. მანამდე [ვებ-აპი](#web-app) მუშაობს Safari-ში iPhone-სა და iPad-ზე, კამერით სკანირების ჩათვლით.
