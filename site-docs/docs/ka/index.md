# CimBar

CimBar გადასცემს ფაილს ან ტექსტურ შეტყობინებას ერთი ეკრანიდან კამერას ფერადი ფიგურების ანიმაციური კოდის სახით. არაფერი გადის ქსელში, არ საჭიროებს კაბელს ან დაწყვილებას. გასაგზავნის დაშიფვრა პაროლით შეიძლება. ყველაფერი თქვენსავე მოწყობილობებზე ხდება.
