# როგორ მუშაობს

CimBar იყენებს **CimBar-XL**-ს — ფერადი შტრიხკოდის ფორმატს, რომელიც ეკრანიდან კამერისთვის ფაილების გადასაცემად შეიქმნა. ეს დამოუკიდებელი ფორმატია, შთაგონებული sz3-ის [libcimbar-ითა და CFC-ით](https://github.com/sz3/libcimbar) — Color Icon Matrix Barcode-ის თავდაპირველი პროექტებით — და მათთან თავსებადი არ არის.

## კადრი

თითოეული კადრი 64 × 64 უჯრის ბადეა. კუთხეებში მდებარე ოთხი კვადრატული საორიენტაციო ნიშანი კამერას ბადის პოვნაში ეხმარება, მაშინაც კი, როცა ეკრანი დახრილია ან კუთხით ჩანს. დანარჩენი თითოეული უჯრა 16 ფიგურიდან ერთს შეიცავს 4 ფერიდან ერთში, ანუ 6 ბიტს უჯრაზე. ერთი კადრი 2,880 ბაიტს ატარებს.

## შეცდომების გასწორება

ყოველი კადრის ნაწილი Reed-Solomon-ის შეცდომების გასწორებას ეთმობა. კადრი სწორად იკითხება მაშინაც, როცა მისი ზოგიერთი უჯრა ცდომილებით იკითხება ანარეკლის, დაბინდვის ან მუარის ეფექტის გამო. თითოეული კადრი თავად ფაილის დაახლოებით 2,100 ბაიტს ატარებს.

## ბევრი კადრი, ნებისმიერი თანმიმდევრობით

ერთ კადრზე დიდი ფაილი რამდენიმე კადრად იყოფა. თითოეული კადრი მიუთითებს, რომელ ფაილს ეკუთვნის და რამდენი კადრი სჭირდება ფაილს, ასე რომ მიმღებმა იცის, როდის აქვს საკმარისი.

ფაილის საკუთარი კადრების შემდეგ მოდის **აღდგენითი კადრები**. თითოეული მათგანი ფაილის კადრების ნაზავია, გამოთვლილი ისე, რომ ფაილის ზომის ტოლი კადრების *ნებისმიერი* ნაკრები — ფაილის კადრები და აღდგენითი კადრები ერთად — საკმარისი იყოს მის აღსადგენად. მიმღებს რომელიმე კონკრეტული კადრის დაჭერა არ სჭირდება: გამოტოვებულ კადრს ნებისმიერი შემდეგი კადრი ანაცვლებს.

## შეკუმშვა და დაშიფვრა

დაყოფამდე CimBar ფაილს კუმშავს, თუ ეს მას სულ მცირე 5%-ით პატარავებს (ფოტოები და არქივები, როგორც წესი, უკვე შეკუმშულია და ისე იგზავნება, როგორც არის). შემდეგ, თუ პაროლი მიუთითეთ, შედეგს [შიფრავს](encryption.md).

## ყველაფერი თქვენს მოწყობილობებზე რჩება

კოდირება და გაშიფვრა მთლიანად თქვენს ტელეფონზე ან ბრაუზერში ხდება. კოდი მხოლოდ სინათლის სახით მოგზაურობს — ეკრანიდან კამერამდე.

## თავსებადობა

CimBar-ის ყველა მიმდინარე კლიენტი (ვები, Android, iPhone) ერთმანეთის კოდებს კითხულობს. პროექტის ყველაზე ადრეული ვერსიებით, ამ ფორმატამდე შექმნილი GIF-ები არ იკითხება და თავიდან უნდა შეიქმნას.

ფორმატი ღიაა: მისი სპეციფიკაცია და მთელი წყაროს კოდი [GitHub](https://github.com/mezinster/cimbar)-ზეა.
