# CimBar

CimBar передаёт файл или текстовое сообщение с одного экрана на камеру другого устройства в виде анимированного кода из цветных фигур. Ничего не идёт по сети, не нужны ни кабель, ни сопряжение. Отправляемое можно зашифровать паролем. Всё происходит на ваших собственных устройствах.

## Как пользоваться

1. **[Отправьте](send.md):** выберите файл или наберите сообщение. CimBar превратит его в анимированный код.
2. **Покажите** код на экране или поделитесь им как GIF.
3. **[Примите](receive.md):** наведите на код камеру другого устройства и дождитесь, пока соберутся все кадры.

Любой клиент может отправлять любому другому: телефон может принять из веб-приложения, а веб-приложение — с телефона.

В разделе [Как это работает](how-it-works.md) рассказано, что находится внутри кода. О паролях — в разделе [Шифрование](encryption.md).
