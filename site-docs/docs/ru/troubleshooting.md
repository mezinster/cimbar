# Решение проблем

## Сканер не находит код

- Поместите весь код внутрь квадрата, оставив небольшой отступ вокруг. Все четыре угловых квадрата должны быть видны.
- Увеличьте яркость экрана отправителя и избегайте отражений ламп или окон на нём.
- Держите телефон неподвижно и примерно параллельно экрану.
- Следуйте подсказке на экране: **Поднесите ближе**, **Отодвиньте дальше**, **Держите неподвижно**, **Измените угол или освещение** (в веб-приложении: **Держите камеру прямо напротив экрана**).
- **Веб-приложение:** для сканирования камерой страница должна быть открыта по `https://`. Если браузер запросил доступ к камере, а вы отказали, разрешите его в настройках сайта в браузере.
- **Приложение:** если вы запретили доступ к камере, разрешите его для CimBar в настройках системы.

## Счётчик перестал расти

- Не останавливайте показ кода. У показываемого кода новые кадры не заканчиваются; GIF повторяется, так что дождитесь следующего круга.
- Для длинных кодов выберите на стороне отправителя скорость помедленнее (400 мс): телефон может пропускать слишком быстро сменяющиеся кадры.
- Волнистые полосы на экране (муар) возникают из-за наложения сетки пикселей камеры и экрана: отойдите чуть дальше или немного измените угол.

## Кадров в файле: N — используйте «Живое сканирование»

На фотографии помещается только один кадр. В приложении фотография подходит только для кодов из одного кадра; для более длинных используйте **Живое сканирование**.

## Веб-приложение спрашивает, сбросить ли текущее сканирование

Только что добавленная фотография или кадр относится к другому файлу, а не к тому, который сейчас собирается. Решите, оставить уже собранные кадры или начать заново с новым файлом.

## Неверный пароль

Введите его ещё раз: кадры сохранены, сканировать заново не нужно. В паролях различаются заглавные и строчные буквы. Если пароль никто не знает, файл открыть не получится. См. [Шифрование](encryption.md).

## «Недопустимый или неподдерживаемый GIF файл»

Этот GIF не является кодом CimBar или был изменён по дороге: некоторые мессенджеры пережимают GIF или превращают их в видео. Отправьте его как файл (документ) или используйте **Показать на экране** и сканируйте напрямую. GIF-файлы самых ранних версий проекта текущие версии не читают.

## «Файл слишком большой для обработки»

Файл больше, чем может обработать CimBar. Для отправки через **Поделиться GIF** держите код в пределах 500 кадров; **Показать на экране** справляется с кодами до 4096 кадров.

## Приложение не может открыть принятый файл

Сообщение «На этом телефоне нет приложения, которое может открыть этот файл» означает, что ни одно установленное приложение не работает с этим типом файлов. Вместо этого нажмите **Сохранить на устройство** или перешлите файл.
