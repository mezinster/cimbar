# Шифрование

Если вы отправляете с паролем, файл или сообщение шифруется на вашем устройстве ещё до того, как стать кодом. Отсканировать код может кто угодно, но открыть его содержимое — только тот, кто знает пароль.

- **Алгоритм:** AES-256-GCM. Ключ получается из пароля с помощью PBKDF2-SHA256 (150 000 итераций) и случайной соли, своей для каждого файла.
- **Пароль никогда не покидает ваше устройство.** Он не сохраняется, не записывается в журналы и никуда не отправляется.
- **Получателю не нужно знать об этом заранее.** CimBar сам распознаёт зашифрованный файл и спрашивает пароль, когда соберутся все кадры.
- **Неверный пароль ничего не стоит.** Кадры уже собраны: введите пароль ещё раз, сканировать заново не нужно.

!!! warning "Забытый пароль восстановить нельзя"
    Никто, в том числе мы, не сможет открыть зашифрованный файл без пароля.

Сообщите получателю пароль не через сам код, а другим способом — например, лично.
