# Как это работает

CimBar использует **CimBar-XL** — цветной формат штрихкода, созданный для передачи файлов с экрана на камеру. Это самостоятельный формат, вдохновлённый проектами [libcimbar и CFC](https://github.com/sz3/libcimbar) автора sz3 — исходными проектами Color Icon Matrix Barcode, — и с ними он несовместим.

## Кадр

Каждый кадр — это сетка 64 × 64 ячейки. Четыре квадратных поисковых узора по углам помогают камере найти сетку, даже если экран наклонён или виден под углом. Каждая из остальных ячеек содержит одну из 16 фигур одного из 4 цветов — это 6 бит на ячейку. Один кадр несёт 2880 байт.

## Исправление ошибок

Часть каждого кадра отведена под код исправления ошибок Рида–Соломона. Кадр читается правильно, даже если часть ячеек распознана неверно из-за бликов, размытия или муара. Собственно данных файла в каждом кадре около 2100 байт.

## Много кадров, любой порядок

Файл, который не помещается в один кадр, делится на несколько. Каждый кадр сообщает, к какому файлу он относится и сколько кадров нужно для этого файла, поэтому получатель знает, когда кадров достаточно.

После собственных кадров файла идут **ремонтные кадры**. Каждый из них — смесь кадров файла, рассчитанная так, что *любой* набор кадров размером с файл — хоть кадры файла, хоть ремонтные — позволяет его восстановить. Получателю не нужно ловить какой-то определённый кадр: пропущенный кадр заменит любой следующий.

## Сжатие и шифрование

Перед разбиением CimBar сжимает файл, если это делает его меньше хотя бы на 5% (фотографии и архивы обычно уже сжаты и отправляются как есть). Затем, если вы указали пароль, результат [шифруется](encryption.md).

## Всё остаётся на ваших устройствах

Кодирование и декодирование целиком выполняются на вашем телефоне или в браузере. Код передаётся только светом — с экрана на камеру.

## Совместимость

Все текущие клиенты CimBar (веб, Android, iPhone) читают коды друг друга. GIF-файлы, созданные самыми ранними версиями проекта, ещё до этого формата, не читаются, и их нужно создать заново.

Формат открыт: его спецификация и весь исходный код опубликованы на [GitHub](https://github.com/mezinster/cimbar).
