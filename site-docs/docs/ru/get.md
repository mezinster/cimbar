# Установка

## Веб-приложение { #web-app }

Откройте **[nfcarchiver.com/cimbar](https://nfcarchiver.com/cimbar/)** в браузере. Оно работает на телефонах и компьютерах, не требует установки и учётной записи.

Для сканирования камерой страница должна быть открыта по `https://` (как по этому адресу). Копия, открытая из файла на компьютере, по-прежнему умеет отправлять и расшифровывать GIF или фотографии, но браузер не запустит в ней сканер камеры.

## Android { #android }

Приложение называется **CimBar Scanner**. Нужен Android 7.0 или новее. Оно просит одно разрешение — камеру — и не имеет доступа к интернету.

- **[F-Droid](https://f-droid.org/packages/com.nfcarchiver.cimbar/)**: F-Droid собирает приложение из опубликованного исходного кода и обновляет его автоматически через приложение F-Droid.
- **[Релизы на GitHub](https://github.com/mezinster/cimbar/releases)**: APK прикреплён к каждому релизу.

!!! note "Сборки F-Droid и GitHub несовместимы"
    F-Droid подписывает свои сборки собственным ключом, поэтому APK с GitHub не может обновить установку из F-Droid, и наоборот. Чтобы перейти на другой источник, сохраните расшифрованные файлы, удалите приложение и установите его заново из другого источника.

У версий до 0.10.1 включительно был другой идентификатор приложения (`com.cimbar.scanner`). Более новые версии устанавливаются рядом со старым приложением, а не заменяют его. Сохраните из старого нужные файлы, а затем удалите его.

## iPhone и iPad { #iphone }

**CimBar** для iPhone и iPad (iOS 15 или новее) проходит тестирование в Apple **TestFlight** и пока не опубликован в App Store. До тех пор [веб-приложение](#web-app) работает в Safari на iPhone и iPad, включая сканирование камерой.
